BAIT UL ILM SCHOOL MANAGEMENT APP — PWA PACKAGE v0.2

This package adds:
- Android/iOS-style app manifest
- 192x192 and 512x512 home-screen icons
- Standalone display mode
- Updated offline cache

IMPORTANT:
A PWA must be hosted on an HTTPS website to be installable through a normal mobile browser.
Opening index.html directly from a ZIP or file manager does not enable PWA installation.
This package is still a local prototype. It does not yet provide secure multi-user accounts
or online multi-device synchronization. Do not enter sensitive live student records yet.

ANDROID INSTALL:
1. Publish/extract this package to an HTTPS website.
2. Open that website in Chrome on Android.
3. Open Chrome menu (three dots).
4. Tap "Install app" or "Add to Home screen".
5. Confirm. The Bait ul ilm icon will appear on the home screen.

The hosting/HTTPS step is still required; this ZIP alone cannot install itself.
